1) Что такое Serializer и ModelSerializer? В чём разница?
    ModelSerializer - это готовые сериализаторы, которые автоматичсеки сериализируют данные
    Serializer - здесь мы уже должны вручную сериализировать данные

2) Для чего нужны mixins?
    Mixins - это готовые классы, которые который реализуют CRUD

3) Как запретить пользователю просматривать чужие бронирования?
    С помощью метода IsOwnerOrAdmin в папке permissions.py

4) В чём разница между GET, POST, PUT, PATCH и DELETE?
    GET - получение данных
    POST - создание данных
    PUT - изменение данных
    PATCH - частичное изменение данных
    DELETE - удаление данных

5) Как запретить клиенту изменять определённые поля через API?
    Через read_only_fields

6) Для чего используется кэширование?
    Кэширование нужно для временнего хранения результатов(напрмер при частых заросах в БД)
    Кэш может ускорить работу API
    А также экономятся ресурсы

7) Для чего нужна документация Swagger?
    Чтобы frontend-разработчик смог понять backend-код
    Также он позволяет отправлять запросы прямо из браузера без использования других программ вроде Postman
